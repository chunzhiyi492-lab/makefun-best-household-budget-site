**NestEgg — Household Budget.** A warm, paper-like household budget site for the fictional Miller family, November 2026. Six working pages: a dashboard with income, spending, savings and a hand-drawn donut chart; a transactions ledger you can add to, filter, search and delete from; an editable budget by category; savings goals you can top up; recurring bills you can mark paid; and a six-month income-vs-spending report with a grouped bar chart. Everything runs offline from static files — no network requests, no account — and every edit saves in the browser's local storage.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a browser (desktop or phone).
